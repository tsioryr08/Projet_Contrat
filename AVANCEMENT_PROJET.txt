# AVANCEMENT DU PROJET - SUIVI DES CONTRATS FOURNISSEURS

Date de génération : 2026-10-28
Branche actuelle : feature-oli
Stack : PHP 8.4 + CodeIgniter 4.7.2 + MySQL/MariaDB 10.4

Ce document permet à toute personne de comprendre rapidement où en est le projet sans devoir relire tout le contexte.

## 1. Vue d'ensemble

Le projet vise à gérer le suivi des contrats fournisseurs avec alertes J-30/J-10/J-0, workflow de litiges, extraction IA de clauses et tableau de bord des échéances.

Répartition : **Olivier** (socle, contrats, alertes, litiges, IA, tableau de bord) / **Tsiory** (gabarit, référentiels, suivi, exports, documentation).

**Tests/Démo** : `/demo` (à retirer avant rendu)

## 5. Fonctionnalités clés opérationnelles

### Tsiory (référentiels + suivi)
- **Fournisseurs** : CRUD complet, validation NIF/STAT/téléphone, unicité, contacts, évaluations, liste contrats
- **Services** : CRUD avec responsable, refus suppression si utilisé, audit
- **Types de contrat** : CRUD par famille, activation/désactivation, valeurs par défaut
- **Règles d'alertes** : paramétrage J30/J10/J0 (jours, gravité, notifier supérieur, actif)
- **Obligations** : CRUD depuis fiche contrat/liste globale, filtres, statut automatique en_retard (par commande Olivier), suppression cascade alertes
- **Pénalités** : CRUD, calcul retard découverte (rouge > 30j), totaux par statut, lien litige facultatif
- **Utilisateurs** : CRUD, hash mot de passe, réinitialisation, désactivation impossible si soi-même, filtrage par rôle
- **Exports CSV** : fournisseurs, contrats, pénalités, obligations, échéances (UTF-8 BOM, point-virgule)

### Olivier (métier contrats)
- **Authentification** : rôles admin/juriste/responsable/direction/lecteur, filtres
- **Contrats** : formulaire, transitions de cycle de vie, historique, clauses
- **Alertes** : génération via commande, lecture/traitement
- **Litiges** : workflow signalement→qualification→médiation→résolution→archivage, transitions contrôlées
- **IA** : upload PDF/DOCX, extraction, validation humaine, confidentiel protégé
- **Tableau de bord** : vue échéances, niveaux
- **Analyse IA** : recommandations, décision humaine

### Transversal
- **Audit** : `audit_log()` sur créations/modifications/suppressions, écran `/audit` (admin/direction)
- **Gabarit** : `layouts/main`, menu par rôle, badges, pagination Bootstrap
- **Sessions simulées** : `/demo` disponible
